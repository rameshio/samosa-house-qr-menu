## 2026-09-03 LogoIntro Flash
- **Error**: Menu flashed visibly for 1 second on first visit before the welcome video appeared.
- **Root Cause**: The `LogoIntro` container wrapper had an `opacity-0` default state that transitioned to `opacity-100` only after the video emitted the `playing` event. This meant the underlying menu was completely visible until the video finished buffering.
- **Correction**: Set the container wrapper to `opacity-100 pointer-events-auto` unconditionally on mount to block the screen instantly. Moved the `opacity-0` to `opacity-100` transition onto the `<video>` element itself, ensuring black buffering frames are hidden but the menu is safely covered by the Saffron background. Body scroll was also locked immediately upon mount. Updated 16 automated tests to assert the new opacity states.

## 2026-09-03 Category Navigation Initialization
- **Error**: The first category (Appetizers) appeared faint, hidden, or disabled on initial load when refreshing at the top of the page.
- **Root Cause**: activeCategoryId in useCategoryScroll was asynchronously initialized to `null`, causing the initial render to pass `null` to CategoryNavigation. Additionally, the gooey navigation effect used an SVG matrix filter that degraded text rendering, leading to the text being duplicated into a separate span and the actual `<a>` tag being made transparent with pointer-events: none. If the positioning effect failed to fire precisely before layout, the text appeared hidden or unclickable.
- **Correction**: Updated useCategoryScroll to synchronously derive and set the initial active category before the first render completes. Restructured CategoryNavigation to separate the gooey SVG filter background layer from the foreground interactive text layer, eliminating the need for duplicate text spans and pointer-events: none. Active categories now simply use `text-white drop-shadow-md` and `aria-current="page"`. Added comprehensive tests to verify synchronous hook initialization.
